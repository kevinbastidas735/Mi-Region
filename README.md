# Conociendo mi región: Nariño

## Descripción del proyecto

Este proyecto consiste en una página web sobre la región de Nariño, Colombia. Su objetivo es mostrar información sobre sus lugares turísticos, su cultura, sus tradiciones y algunas de sus comidas típicas.

La página fue desarrollada utilizando HTML para organizar el contenido y CSS para darle diseño y estilo.

## Tecnologías utilizadas

- **HTML5:** permite organizar los títulos, textos, imágenes y secciones de la página.
- **CSS3:** permite personalizar los colores, tamaños, espacios y la distribución de los elementos.

## Contenido de la página

- **Inicio:** presenta información general sobre Nariño y la ciudad de Pasto.
- **Lugares turísticos:** muestra el Santuario de Las Lajas, la Laguna de La Cocha y el volcán Galeras.
- **Cultura:** presenta información sobre el Carnaval de Negros y Blancos.
- **Comida típica:** menciona platos como el cuy asado, el locro y las empanadas de añejo.

## Características

- Menú de navegación para acceder a las secciones.
- Imágenes relacionadas con la región.
- Tarjetas para presentar lugares turísticos.
- Diseño con colores y estilos personalizados mediante CSS.
- Adaptación de la distribución para pantallas pequeñas mediante `@media (max-width: 600px)`.
- Pie de página con el nombre del autor y la región de procedencia.

## Organización del código

El archivo `index.html` contiene la estructura y el contenido de la página.

El archivo `css/estilos.css` contiene los estilos visuales, como los colores, los espacios, los bordes y la distribución de los elementos.

La carpeta `img` contiene las imágenes utilizadas en las diferentes secciones.
